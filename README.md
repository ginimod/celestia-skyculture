# celestia-skyculture

11 cultures stellaires américaines pour Celestia

![](logo.webp)

## Contenu 
- Aztec
- Blackfoot
- Inuit
- Lokono
- Maya
- Navajo
- Northern Andes
- Seri
- Tikuna
- Tukano
- Tupi

## Setup

Installer le repository dans le répertoire de travail de Celestia

## Lancement

celestia --conf {celestia_home}/scripts/sk_tour/{SKYCULTURE}/celestia.cfg
